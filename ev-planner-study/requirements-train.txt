# What the training scripts need, declared.

# Until now they ran against whatever the ambient anaconda install happened to
# carry: .venv-etl has geopandas and pyrosm but no scikit-learn, no sqlalchemy
# and no psycopg, so `python3 train_utilisation_model.py` was resolving against
# a base environment nobody had written down. The artifact records the sklearn
# version it was fitted with, which tells you what trained a model AFTER the
# fact; this tells you what will.
#
#     python3 -m venv .venv-train
#     .venv-train/bin/pip install -r requirements-train.txt
#
# Separate from backend-ev-flow/requirements-api.txt on purpose. The API serves
# a fitted artifact and needs 14 packages to do it; nothing here belongs in that
# image, mlflow least of all.

psycopg[binary]>=3.1
